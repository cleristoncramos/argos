# Fase 1 — Etapa 5: Página Sobre o Projeto

## Objetivo

Apresentar o propósito do Argos DataLab, seu contexto acadêmico, suas funcionalidades e seus limites de uso.

## Implementação realizada

Foi criada a página multipágina `app/pages/1_Sobre_o_Projeto.py`.

A página informa que o Argos DataLab é uma ferramenta educacional e de pesquisa para análise exploratória de dados históricos do mercado financeiro. Também descreve consulta de ativos, séries temporais, variações, padrões sazonais, exportação CSV e validação básica dos dados.

## Limites de interpretação

A página registra expressamente que:

- os resultados são baseados em dados históricos;
- o sistema não constitui recomendação ou aconselhamento de investimento;
- desempenho passado não garante resultados futuros.

## Contexto acadêmico

A página identifica o projeto como vinculado ao PIBITI UFPI 2026–2027 e informa o título do plano de trabalho e a orientação acadêmica.

## Resultado

O MVP passou a apresentar de forma transparente seu propósito, escopo, contexto institucional e limitações.
